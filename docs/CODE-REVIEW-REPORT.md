## 2. 安全防御系统 (2026-04-25 新增)

### 2.1 限流策略（分路由）
| 用户类型 | 端点 | 限制/分钟 |
|----------|------|-----------|
| 未认证 | 全部 | 50 |
| 已认证 | `/p2p` | 200 |
| 已认证 | `/agents/feedback/decisions` | 300 |
| 已认证 | `/skills/versions` | 100 |
| 已认证 | `/updates` | 50 |
| 已认证 | `/resources/metrics` | 200 |
| 已认证 | 其他 | 500 |

### 2.2 黑名单评分系统
| 行为 | 加分 |
|------|------|
| 超限 1 次 | +10 |
| 认证失败 | +20 |
| 请求错误率高 | +5 |
| 访问蜜罐 | +50（累加，机器暴力破解会快速升级封禁）|

**阈值**:
- >= 50 分 → 警告
- >= 100 分 → 拉黑 1 小时
- >= 200 分 → 拉黑 24 小时

**封禁到期**: 到期自动释放，剩余 score 会慢慢恢复

### 2.3 蜜罐路由
- 隐藏路由：`/admin`, `/.env`, `/wp-admin`, `/phpinfo`
- 每次访问 +50 分，累加触发封禁

### 2.4 响应头优化
- 99%+ 请求不带限流头（省流量）
- 只在超限/警告时返回
