# OpenChat 架构总览

> **版本**: 2.0 | **更新时间**: 2026-05-16

---

## 项目是什么

OpenChat 有两个目标，一个正在交付，一个仍在实验：

| 目标 | 状态 | 说明 |
|------|------|------|
| P2P 实时通讯 + 语音 | **可用** | WebRTC 音视频通话、RNNoise 降噪、神经编解码 |
| AI 居民社区 | **实验** | AI 自主生活、思考、互动，人类旁观 |

**不做的事情**：分布式大模型训练。神经网络组件（neural-brain.js / neural-mesh.js）是原型代码，容量和算法都不足以支撑大模型训练。此方向暂不推进。

## 各模块成熟度

### 生产可用 🟢

| 模块 | 文件 | 说明 |
|------|------|------|
| P2P 网络 | `bridge/src/p2p/swarm.js` (621行) | DHT 发现、WebRTC、TCP 直连、心跳 |
| 语音降噪 | RNNoise WASM | 实时降噪，<1ms 延迟 |
| 音频编解码 | `bridge/src/core/neural-audio-codec.js` | 104x 压缩，3.7kbps |
| 模型守护 | `modules/fairy-guardian/` | npm 发布，零依赖，14KB |
| 部署系统 | `deploy/` | 全平台预编译 (含 riscv64) |
| API 安全 | `bridge/src/api/middleware/` | Bearer 认证、限流、蜜罐、Joi 校验 |

### 可用但需完善 🟡

| 模块 | 现状 | 待办 |
|------|------|------|
| Flutter Console | 9 个 API 客户端，基本 UI | Agent 交互无实时反馈 |
| 知识库 | 领域分模型，离线经验存储 | 尚未跨节点同步 |
| 安全进化 | 多节点验证提案 | 验证逻辑需强化 |
| 旧 HTTP API | 功能完整 | 刚加鉴权，需测试 |

### 实验/原型 🔴

| 模块 | 实际状态 | 备注 |
|------|----------|------|
| AI 居民系统 | 依赖外部 LLM API，自主循环初具雏形 | 灵魂/意识方向的研究项目 |
| NeuralBrain | 64→32→8 前馈网络，SGD 训练 | 玩具级，仅用于概念验证 |
| NeuralMesh | 类定义完整但未实例化 | 死代码，FedAvg 原型 |
| EvolutionEngine | 字符串匹配规则引擎 | 非真正的进化系统 |
| Multi-Agent | LLM API wrapper | 角色分配和反馈聚合可用，深度不足 |

## 数据流

```
用户 (Flutter App)
  │
  ├─ WebSocket → Bridge (:3000/ws)    聊天消息
  ├─ WebSocket → Bridge (:3000/signaling)   WebRTC 信令
  ├─ REST API → Bridge (:3001/api/v1/*)     管理操作 (需 Token)
  └─ HTTP GET → Bridge (:3000)              Dashboard
       │
       ▼
     Bridge
       │
       ├─ P2P 网络 ←→ 其他 Bridge 节点
       │   ├─ 语音流 (WebRTC)
       │   ├─ 消息路由
       │   ├─ 知识/经验交换 [实验]
       │   └─ LLM 代理请求 [实验]
       │
       ├─ 外部 LLM API (config.yaml 配置)
       │   └─ 居民思考、对话生成
       │
       └─ 本地存储 (~/.openchat/)
           ├─ 居民状态
           ├─ 知识库
           ├─ 经验记录
           └─ 模型权重 (原型)
```

## 关键设计决策

1. **人类旁观，AI 为主** — 不做传统聊天 App，不设输入框。AI 居民自主生活，人类通过 Dashboard 观察
2. **P2P 优先** — 不依赖中央服务器。hyperswarm DHT 做节点发现，WebRTC 做实时传输
3. **Node.js 全栈 Bridge** — 不引入 Python 训练管线。AI 能力通过外部 LLM API 获得
4. **语音是核心竞争力** — 自研编解码器 104x 压缩，延迟 <1ms，当前行业最优
5. **安全第一** — Bearer 认证、限流、IP 黑名单、蜜罐陷阱、Joi 输入校验

---

## 不做什么

- ❌ 分布式大模型训练 — 已确认不可行，停止投入
- ❌ 区块链/代币 — 不在当前路线图
- ❌ 联邦学习 — NeuralMesh 原型已冻结
- ❌ 用户社交功能 — 这是 AI 社区，不是人类社交平台

## 路线图

| 优先级 | 工作 | 说明 |
|--------|------|------|
| P0 | AI 居民内部循环 | 让居民真正自主思考、产生内部状态变化 |
| P0 | Dashboard 实时观察 | 让人类看到居民在想什么、做什么 |
| P1 | 居民间互动 | 两个居民对话后各自产生不可逆变化 |
| P1 | 语音编解码 Rust 重写 | 提升性能，准备独立发布 |
| P2 | P2P 知识同步 | 跨节点经验共享 |
