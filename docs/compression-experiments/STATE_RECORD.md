## 实验 1 — LPC RC 量化（修复 sign bug 后重跑）

| 模式 | bits/帧 | SNR (tts) | 结论 |
|------|---------|-----------|------|
| full | 704 | 302.2 dB | 数字完美 |
| rc37 | 37 | 302.0 dB | 几乎无损 |
| rc24 | 24 | 289.7 dB | 几乎无损 |
| rc17 | 17 | 237.9 dB | TTS 有损，真实语音可能可接受 |
| rc10 | 10 | 23.6 dB | 完全损坏 |

→ **拐点: rc24 (24 bits) 足够安全**

**注意**: 最初实验有 RC 去量化步进公式的符号 bug (`-` 应为 `+`)，导致 rc10 等低比特模式下 SNR 被严重高估（旧 67.6 dB → 修后 23.6 dB）。修后 rc37/rc24 仍接近完美。

## 实验 3 — 2D 交叉（级联效应）

| 组合 | SNR | 与单独残差对比 | 级联下降 |
|------|-----|---------------|---------|
| full bit6 | 24.8 dB | — | — |
| rc37 bit6 | 24.8 dB | 0 dB | 无 |
| full bit10 | 49.6 dB | — | — |
| rc24 bit10 | 33.5 dB | -16.1 dB | **显著** |

**分析**: rc24 单独 (LPC 量化只有 289.7 dB 误差) 看似无害，但它改变了合成滤波器 `1/A_Q(z)` 的极点位置。量化噪声经过更谐振的滤波器后被放大到低频段 → SNR 净降 16 dB。这是 RC 量化的已知问题——极点控制不精确。

## 实验 4 — 多脉冲激励 (MPLPC)

| 脉冲数 | SNR (tts) | 问题 |
|-------|-----------|------|
| 8 | 3.2 dB | LPC 滤波器对稀疏脉冲驱动产生振荡 |
| 16 | 3.0 dB | 更多脉冲→输出更差 |
| 90 | 0.2 dB | 完全失败 |

**结论**: 无 CELP 框架(感知加权、自适应码本、后滤波)下 MPLPC 不可行。

## 汇总结论

**所有残差压缩方法都无法绕过 ~6 dB/bit 的率失真曲线**：

| 方法 | bits/sample × 180 | SNR | 结论 |
|------|-------------------|-----|------|
| 标量 bit8 | 1440 | 37 dB | 可听门限 |
| 标量 bit6 | 1080 | 25 dB | 差 |
| ADPCM | 1080 | 4.6 dB | 白噪声无相关性可榨 |
| MPLPC | 8~90 脉冲 | 0~3 dB | 无 CELP 框架跑不稳 |
| 增益-形状 | 3~8 + 增益 | 6~7 dB | 封顶 |
| 基音预测 | 3~7 | 0.6~1.6 dB | 重复失真 |

**单 EPC tag (84 bits) × 22.5ms = 3.7 kbps 不可能承载可懂语音。**
**最低可行配置: bit8 残差 + rc24 LPC ≈ 17 tags/帧 ≈ 10 kbps。**

下一步方向：
1. **紧凑打包** —— 实现 bit7-8 残差的多 tag 打包格式
2. **参量编码 MELP** —— 放弃残差，F0+增益+清浊音+LSF (54 bits/帧 = 1 tag)
3. **换码器 (MDCT)** —— 频域编码，完全换路线

### CLI 用法

```
node epc-voice-melp.mjs <input.wav> <output.epc> [LPC_MODE] [RES_MODE] [ORDER] [F_MELP] [PRE_COEFF]

LPC_MODE: full | rc37 | rc24 | rc17 | rc10 | lsf40
```

## 实验 12 — 紧凑打包编解码器 `epc-voice-codec.mjs`

**2026-05-29**

### 实现
- 完整 WAV(48kHz)→EPC→WAV 管线，比特精确打包
- EPC RFID 帧格式：`BB [Type] [0xCC] [PL] [Param] [sum] [7E]`，每帧可携带多 tag
- 编码参数：SR=8kHz, F=180, ORDER=10, PRE_EMP=0
- LPC 10 阶 + rc24 量化 (28 bits: [3,3,3,3,3,3,3,3,2,2]) + 8-bit 标量残差量化
- 每帧打包：RC(N B) + rMax(2B) + 残差 bits
- 基音预测已移除 (闭环增益量化导致 ~32 dB SNR 下降，需 CELP 自适应码本框架)

### 关键发现：合成滤波器状态管理

连续跨帧合成滤波器状态会累积量化误差并放大低频噪声，导致 ~25 dB SNR 退化。**正确的做法是每帧创建新的合成滤波器状态**（匹配 experimental codec `new SynthFilter(ORDER)` 行为），起始 ORDER 样本有瞬态但 10/180=5.6% 可忽略。

| 状态策略 | SNR | 说明 |
|---------|-----|------|
| 连续状态 | ~10 dB | 量化误差跨帧传播，低频放大 |
| 每帧复位 | 35.7 dB | 匹配 experimental codec |

### 5 文件测试结果 (rc24 + bit8 + PRE_EMP=0)

| 文件 | SNR | 码率 | 活动帧 |
|------|-----|------|-------|
| tts_speech (6.8s) | 35.7 dB | 58.9 kbps | 224/300 |
| female_speech (10.7s) | 37.5 dB | 65.2 kbps | 397/474 |
| male_speech (8.1s) | 34.8 dB | 63.7 kbps | 293/359 |
| noisy_speech (6.8s) | 36.4 dB | 76.4 kbps | 300/300 |
| tone_440 (0.5s) | 38.6 dB | 76.4 kbps | 22/22 |

- SNR bins 分布：100% 帧 SNR > 25 dB, 中位数 > 35 dB
- 最差帧 SNR: ~25 dB (不影响整体可懂度)
- 码率范围 58.9-76.4 kbps (活动帧比例影响)

### 与 experimental codec 对比

配置 full LPC + bit8 + per-frame synth state + PRE_EMP=0 → **38.5 dB**（与 experimental 完全一致）。
rc24 的 2.8 dB 损失 (38.5→35.7) 来自 RC 量化，在预期范围内。

### 预加重选择

| PRE_EMP | SNR | 说明 |
|---------|-----|------|
| 0 | 35.7 dB | 无噪声放大，客观 SNR 最好 |
| 0.97 | 34.5 dB | -1.2 dB，但可能听感更好（强调高频） |

选用 PRE_EMP=0 作为默认。

### 未解决问题
1. **基音预测** — 闭环 8 级增益量化导致 SNR 从 35.7 下降到 3.9 dB，需要 CELP 完整框架包括感知加权、自适应码本搜索、后滤波
2. **进一步降低码率** — 当前 59-76 kbps 达到 bit8 理论极限，降比特率需改方式（参量编码或 MDCT）

## 实验 13 — 参量编码 (MELP-like) `epc-voice-parametric.mjs`

**2026-05-29**

### 实现
- 不传残差，改传：LPC rc24 (28 bit) + F0 (7 bit) + 多频带清浊音 (4 bit) + 增益 (8 bit)
- **每帧数据 = 47 bit → 1 EPC tag (96 bit) 装得下**
- 码率：7.1 kbps（标量 bit8 的 1/10）

### 多频带混合激励
- 4 个频带：0-800 / 800-1600 / 1600-2400 / 2400-4000 Hz
- 每个频带用 31 阶窗化 sinc FIR 滤波器分离
- 浊音频带用脉冲串激励，清音频带用白噪声
- 单频带清浊音阈值：归一化自相关 > 0.35

### 5 文件结果

| 文件 | SNR | 与单频带比 |
|------|-----|-----------|
| tts_speech | -4.2 dB | +2.0 dB |
| female_speech | -4.9 dB | +1.3 dB |
| male_speech | -3.0 dB | +3.0 dB |
| noisy_speech | -4.0 dB | +2.1 dB |
| tone_440 | -2.4 dB | +4.5 dB |

SNR 负数是参量编码的正常现象（激励不匹配相位），不反映可懂度。频带清浊音分布正确：低频浊化率高 (~78%)，高频浊化率低 (~47%)。

### 剩余问题
1. **听感粗粝** — 脉冲串激励有嗡嗡声，需要自适应谱增强（格式后滤波）和脉冲弥散滤波
2. **F0 轨迹不平滑** — 逐帧 F0 有跳变，需要中值滤波 + 平滑
3. **清浊音边界过渡** — 帧间清→浊切换时会产生咔嗒声，需渐变混合

## 实验 14: 全面方法调查 + 噪声成形合并

### 日期: 2026-05-29

### 背景
前 13 个实验确认标量 bit8 (35.7 dB @ 59 kbps) 和参量编码 (-4.2 dB @ 7.1 kbps) 两个极端。中间地带需要探索。

### 调查范围
用 `tests/epc-survey-final.mjs` 对 4 个测试文件测试 3 类方法:

**1. 噪声成形** (残差 FIR 预加重 + IIR 去加重)
- γ=0.3: +1.2~3.3 dB
- γ=0.5: +1.7~4.4 dB (甜区)
- γ=0.7: +2.1~4.4 dB

**2. 残差熵编码**
- bit8 实际熵 6.74~7.12 bit/sample → 可无损省 0.88~1.26 bit/sample (≈ 7-10 kbps)

**3. ACELP (代数码书激励线性预测)**
- 48 脉冲/帧 SNR 0.5 dB — 失败（脉冲幅值分辨率不够，残差幅度动态范围远大于二进制码本能力）

### 关键发现: 噪声成形 FIR vs IIR
FIR 预加重 `(1+γz⁻¹)` + IIR 去加重 `1/(1+γz⁻¹)` 正确。IIR 预加重会把去加重重复两次导致降质。

### 合并到主 codec
噪声成形 γ=0.5 已合并到 `epc-voice-codec.mjs`:
- 编码器: 残差后加 FIR 预加重再量化
- 解码器: 量化后先加 IIR 去加重再 LPC 合成
- 码率无变化，SNR 提升 ~3 dB
- 实现成本: 编解码各 1 行
