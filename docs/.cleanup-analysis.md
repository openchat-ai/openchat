## ✅ 遵循的规则

根据 rules.md 和 arch.md：

✓ **Rule 6**: 开发原则 - 短步快跑
  - 每次只实现一个小功能
  - 演示代码违反此原则，应该移除

✓ **Rule 11**: Harness Engineering - 接力跑模式
  - 不同阶段应该独立，演示代码混淆了这一点

✓ **Plan**: 文件组织
  - plan.md 定义新代码应在 packages/ 下
  - 根目录应该只有配置和主入口文件

✓ **Architecture**: 关注点分离
  - 演示代码混合了业务逻辑和展示层
  - 应该完全分离
