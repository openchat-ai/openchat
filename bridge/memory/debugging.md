# 调试经验记忆

> 触发词：调试、debug、bug、错误、error

## 常见问题

### P2P 连接问题
- **问题**: hyperswarm DHT bootstrap 失败 (海外节点)
  - **解决**: 使用 Qiniu 作为国内 rendezvous

- **问题**: TCP 粘包
  - **解决**: 4字节长度头帧解析

- **问题**: WebSocket 信令连接失败
  - **解决**: 检查 /signaling 端点和房间隔离

### SafeEvolution 问题
- **问题**: 邻居验证超时
  - **解决**: 增加 timeout 容忍度

- **问题**: 看门狗误报
  - **解决**: 区分 5s/30s 场景

- **问题**: .bak 备份冲突
  - **解决**: 使用时间戳命名

### 热回滚问题
- **问题**: 回滚后仍报错
  - **解决**: 多层备份，最老备份兜底
