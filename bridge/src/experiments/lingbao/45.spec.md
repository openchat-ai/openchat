# spec: 45 — calendar-parse（施工日历解析+阈值动态调整）
> 灵保 L2 子任务 9 落地。读施工日历（浇筑/吊装/收尾），输出"建议调整"清单。

## 数据流
```
输入: { calendar: [{date, phase, equipmentLoadKw}], thresholds: {leakMa, arcEnergy, overloadKw} }
   ↓
phase 表查找 → 当前 phase 期望负载 vs 阈值
   ↓
输出: { suggestions: [{date, phase, action, reason, adjusted}] }
```

## 接口签名
```ts
function parse(calendar: Array<{date: string, phase: string, equipmentLoadKw?: number}>): { days: number, phases: Record<string, number>, dateRange: [string, string] }
function suggest(calendar, thresholds, currentDate?): { currentPhase, suggestions: Array<{date, phase, action, reason, adjusted: {leakMa?, arcEnergy?, overloadKw?}}> }
```

## 边界条件
- calendar 为空 → 返回空 suggestions, 不抛
- phase 字符串非枚举值 → 标 'unknown', 给保守建议
- thresholds 缺字段用默认值 {leakMa: 30, arcEnergy: 0.15, overloadKw: 50}
- currentDate 不传 = 用最后一天
- 建议规则 (硬编码):
  - phase='浇筑' (concrete) → overloadKw 阈值 +50%
  - phase='吊装' (lifting) → leakMa 阈值 -10% (严防漏电)
  - phase='收尾' (finishing) → arcEnergy 阈值 -20% (电弧敏感)
  - phase='休整' (rest) → 所有阈值恢复默认
