# spec: 40 — waveform-sim（漏电流合成波形生成器）
> 灵保 L1/L2 数据合成层原语。产合成漏电波形（30mA 阈值、200ms 截取、谐波分量）
> 供子任务 5/6/7/8（算法验证）使用。无真硬件依赖。

## 数据流
```
输入: { op, scenario, sampleRate, durationMs, leakLevelMa, noiseLevel }
   ↓
WaveformSim.generate()
   ↓
合成基础正弦 (50Hz) + 漏电分量 (0~1000Hz) + 高斯白噪声 + 偶发尖峰
   ↓
输出: { samples: Float32Array, sampleRate, durationMs, stats: { rms, peak, thd } }
```

## 接口签名
```ts
class WaveformSim {
  constructor(config?: { sampleRate?: number = 12800, mainsFreq?: number = 50 })
  generate(opts: {
    durationMs: number,           // 总时长
    leakStartMs: number,          // 漏电起始时刻
    leakLevelMa: number,          // 漏电幅值 (mA)
    scenario?: 'normal' | 'leak' | 'arc' | 'overload',  // 预设场景
    noiseDb?: number,             // 噪声 dB (默认 -40)
  }): { samples: Float32Array, sampleRate: number, leakDetected: boolean, stats: object }
}
```

## 边界条件
- `durationMs < 50` → 抛 `RangeError`
- `leakLevelMa < 0` → 抛 `RangeError`
- `sampleRate` 非 [8000, 48000] → 抛 `RangeError`
- 漏电起始在最后 10ms → 截取窗口不足，标 `leakDetected: false`
- Float32Array 必须 little-endian 输出为 Buffer (16-bit PCM 兼容)

## 不变量
```js
// === invariants ===
// - sampleRate 默认 12800 (漏电监测常用, 256 点/周期 @ 50Hz)
// - 漏电幅值单位 mA, 内部归一为电压 (假设 CT 变比 1V/30mA)
// - 输出 Float32Array 长度 = sampleRate * durationMs / 1000
// - 场景 'leak' 必须包含至少 1 个 50Hz 周期内的漏电尖峰
// - 噪声用 Box-Muller 变换生成, seed 可选 (默认 null = 非确定性)
```
