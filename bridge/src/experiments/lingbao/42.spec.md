# spec: 42 — mqtt-push（告警推送模拟）
> 灵保 L3 云端推送层原语。子任务 10 落地。
> 无真 broker 依赖 — 用 in-process EventEmitter 模拟，本地自测即可。

## 数据流
```
输入: { op, channel, payload }  // op: publish | subscribe | history
   ↓
mqttPush.publish() → 内置 EventEmitter + 内存队列 (last 100)
   ↓
订阅者通过 channel 收到 payload, 带 timestamp + deliveryId
```

## 接口签名
```ts
class MqttPush {
  publish(channel: string, payload: object): { deliveryId: string, ts: number, subscribers: number }
  subscribe(channel: string, handler: (msg) => void): { unsub: () => void }
  history(channel: string, limit?: number): Array<{ deliveryId, ts, payload }>
  stats(): { channels: number, totalDelivered: number }
}
```

## 边界条件
- `channel` 空字符串 → `RangeError`
- `payload` 非对象 → `RangeError`
- 内存队列上限 100, 超出 FIFO 丢弃
- 单进程模拟, 跨进程需替换为真 broker (aedes/mosquitto)
- handler 抛异常不影响其他订阅者
