# spec: 44 — doc-gen（报告生成器）
> 灵保 L4 业务层原语。子任务 13/14/15 文档输出。
> 无外部依赖 — 输出 Markdown/CSV/JSON 三种纯文本格式, 可被 pandoc/Excel 二次转 Word/PDF/XLSX。

## 数据流
```
输入: { op, kind, data, meta? }  // kind: report | questionnaire | roi | proposal
   ↓
renderer.render() → 字符串
   ↓
返回 { content: string, ext: 'md'|'csv'|'json', bytes }
```

## 接口签名
```ts
function render(kind: 'report' | 'questionnaire' | 'roi' | 'proposal', data: object, meta?: object): { content: string, ext: string, bytes: number }
```

## 边界条件
- `kind` 必须是 4 种之一, 否则 `RangeError`
- `data` 必须为对象
- `content` UTF-8 字符串, `bytes` = Buffer.byteLength
- 输出格式:
  - `report` → Markdown
  - `questionnaire` → CSV
  - `roi` → CSV (key,value)
  - `proposal` → Markdown
