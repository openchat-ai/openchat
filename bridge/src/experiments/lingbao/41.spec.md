# spec: 41 — signal-algo（信号处理算法容器）
> 灵保 L2 算法层原语。互相关/FFT/小波/LSTM 等纯 JS 算法实现（零 Python 依赖）。
> 输入来自 40.waveform-sim 的合成波形，输出分析结果。

## 数据流
```
输入: { op, samples, sampleRate, leakStartMs? }
  ↓
算法分发: crossCorrelate | detectLeak | fft | stft | arcDetect
  ↓
返回 { result, confidence, latency }
```

## 接口签名
```ts
// 互相关 — 灵保子任务 5: 多级漏电时间差定位
function crossCorrelate(a: Float32Array, b: Float32Array, maxLag?: number): { lag: number, peak: number, confidence: number }

// 漏电检测 — 灵保子任务 4/6: 阈值触发 + 波形截取
function detectLeak(samples: Float32Array, sampleRate: number, thresholdMa?: number): { triggered: boolean, startIdx: number, endIdx: number, peakMa: number }

// FFT — 灵保子任务 7: 电弧高频检测
function fft(samples: Float32Array): { real: number[], imag: number[], magnitudes: number[], peakFreq: number }

// arc 频段能量 — 灵保子任务 7
function arcEnergy(samples: Float32Array, sampleRate: number, bandHz?: [number, number]): { energy: number, isArc: boolean }
```

## 边界条件
- `samples.length < 64` → `RangeError`
- `crossCorrelate` 输入两数组长度必须一致
- FFT 长度自动补零到 2 的幂（不截断原始数据）
- `detectLeak` 阈值默认 30mA, 用窗口峰值 (mA) 而非 RMS
- `arcEnergy` 默认频段 8kHz-12kHz; 配 40.waveform-sim arc 场景 (4k/5.5kHz) 用 `[3000, 6000]`
- `crossCorrelate(a, b, lag)` lag 符号约定: lag=+10 表示 b 向右挪 10, 即 b 早 a 10 sample; 反之 b 晚 a → lag=-10
