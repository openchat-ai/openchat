# spec: cap-60 档 3 retry/recover
> M3 能力档位诊断 — 档 3 状态机 + 错误恢复

## 数据流
输入: 5 mini-task 配置 (backend mock + expectedFinalState + expectedKinds)
处理: simulateIdealLLM → 调 backend → 调 recordAttempt → 收集 trace
输出: per-task 评估 (passed/issues/finalState/attempts) + log JSON

## 接口签名
```
run({ inputs: { taskId? } }) → { outputs: { results, count } }
test() → 跑全部 5 task, 写 log, 输出 report
```

## 边界条件
- 5 task 独立, 不共享 state
- 每 task backend 是 mock, 无网络依赖
- maxAttempts 默认 3, t3 显式 3, t5 显式 5
- 评估只看 finalState + attempts + kind 序列, 不看延迟

- mock backend 无副作用
