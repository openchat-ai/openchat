# spec: 42.mjs — Project DNA
> 多项目 DNA 生成 + 查询 + 边界隔离分析

## 数据流
PROJECTS 配置 → scanProject() 逐个扫描 → generateMultiProjectDNA() 合并 → extractInvariants → buildDependencyGraph → writeDNAFile → answerFromDNA

## 接口签名
- `scanProject(project): { project, modules, totalModules, totalExports }`
- `generateDNA(): Promise<...>` — bridge 项目扫描（向后兼容）
- `generateMultiProjectDNA(): Promise<{projects, modules, totalModules, totalExports}>`
- `extractInvariants(): { invariants, totalInvariantBlocks }`
- `buildDependencyGraph(): { nodes, totalFiles }`
- `writeDNAFile(): { ok, path }` — 多项目写入
- `getDNAContext({maxAgeMs}): string` — brief summary for system prompt
- `answerFromDNA(question): { answer }`

## 查询
- `find function X` — 跨项目查找 export
- `hash XXXXXXXX` — 按 hash 查找项目
- `ls path` — 显示模块 exports
- `summary` — 分项目统计
- `hot` — 按导出行排序
- `cat prefix` — 按路径前缀过滤
- `isolate` — bridge 内边界违规分析
