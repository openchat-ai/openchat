# spec: 42.mjs — Project DNA
> 项目 DNA 生成 + 查询 + 边界隔离分析

## 数据流
scan src/ → extractExports → generateDNA → extractInvariants → buildDependencyGraph → writeDNAFile → answerFromDNA

## 接口签名
- `generateDNA(): { modules, totalModules, totalExports }`
- `extractInvariants(): { invariants, totalInvariantBlocks }`
- `buildDependencyGraph(): { nodes, totalFiles }`
- `writeDNAFile(): { ok, path }`
- `getDNAContext({maxAgeMs}): string`
- `answerFromDNA(question): { answer }`

## 边界条件
- src/ 不存在 → 空 DNA
- 文件读取失败 → 静默跳过
- DNA 过期 → 自动刷新 (maxAgeMs 默认 5min)
- isolate 无违规 → "All zones isolated"
- 未知查询 → 返回帮助文本
