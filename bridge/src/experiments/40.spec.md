# spec: Hooks Plugin System (40)
> 注册 preTool/postTool 钩子到 agent-hooks 注册表，验证 3 个内置插件（日志/限流/权限闸）。

## 数据流
on(event, name, fn) → agent-hooks Map → runPre/runsPost → dev-repl/subagent/22.mjs execTool

## 接口签名
- `enableLoggingHook()`: () → unsubscribe — 注册 pre/post logger，记录 callLog
- `enablePermissionHook(gate)`: (tool, args) → { ok, error? } → unsubscribe
- `enableRateLimitHook(maxPerMinute)`: number → unsubscribe
- `getCallLog()`: array — 返回最近 100 条调用记录
- `clearCallLog()`: void

## 边界条件
- gate 非 function → 抛 throw
- runPre 抛异常 → preTool 链中止，postTool 仍跑（cleanup）
- postTool 抛异常 → console.warn 不阻断链
- 日志队列上限 100 条，溢出裁头
