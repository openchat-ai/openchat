# spec: MCP Server (39)
> 实现 MCP (Model Context Protocol) stdio 传输，暴露 openchat 工具供外部 AI 编辑器调用。

## 数据流
stdin (JSON-RPC) → McpServer.handle() → dispatch to tools/list or tools/call → stdout (JSON-RPC)

## 接口签名
- `class McpServer` — 核心服务器。handle(line: string): void 处理单行 JSON-RPC 请求。_send(msg) 写 stdout。
- `startStdioServer()`: McpServer — 绑定 process.stdin data/end 事件启动 stdio 服务器。
- `TOOL_LIST` — 从 coding-tools.mjs 的 TOOLS 转换的 MCP 格式工具列表。

## 边界条件
- 非 JSON 输入 → Parse error (-32700)
- 未知方法 → Method not found (-32601)
- 工具执行抛异常 → Internal error (-32603)
- 无 name 参数 → Invalid params (-32602)
- process.stdin 关闭 → server.close()
- notifications/initialized 静默忽略（不回复）

## 调试检查点
| C | grep 关键词 | 预期 |
|---|------------|------|
| C1 | `initialize` | 握手 → protocolVersion + capabilities |
| C2 | `tools/list` | 返回 ≥30 个工具，含 read_file/grep |
| C3 | `tools/call` | 调用 executeTool，返回 text content |
| C4 | `Parse error` | 非法 JSON → code -32700 |

## 不变量
- _send 只写 stdout，不写 stderr
- handle 内部所有异常被 try-catch 兜底，不崩进程
- 同一 server 实例 handle 串行处理（顺序不保证由调用方保证）
