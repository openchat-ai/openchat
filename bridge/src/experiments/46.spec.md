# spec: 46.mjs — edit-gate 实验
> 验证编辑审查门：dry-run 预览不落盘 + diff 标注 + HASH_STALE + accept/reject

## 数据流
临时文件 → previewEdit(dry-run) → 断言文件未变 → unifiedDiff 断言 -/+ → 失配断言 HASH_STALE → applyEdit(accept) 断言落盘

## 接口签名
- `run({inputs}): Promise<{outputs}>`
- `test(): Promise<{ok, info}>`
- 复用 lib/edit-gate.mjs：previewEdit / unifiedDiff / applyEdit / isWriteTool

## 边界条件
- 所有编辑作用于临时目录 _tmp_edit_gate，绝不触碰真实源码
- dry-run 后文件内容必须逐字节不变
- stripAnsi 后再断言 diff 文本（避免颜色码干扰）
