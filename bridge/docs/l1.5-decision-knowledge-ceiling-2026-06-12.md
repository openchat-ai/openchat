**好 agent 行为**: 探索几次 → 提议 patch (即使不完美) → emit edit_file.
**坏 agent 行为**: 探索 → "我找不到 slashCommands, 请贴出" → break.

## 双 ceiling 拆分

### Ceiling A: 决断力 (M3 特有)

- M3 在"信息不全"时 default = ask user, 即使被 systemMsg 显式禁止.
- 件 5 (c) DECISION block 把 surrender 改成 "propose diff" — M3 学会 produce diff 块, 但 **propose 完 ask "选哪个"**, 没真正决断.
- 件 5 (d) 强倒计时 — M3 倒计时 round 触发后仍 ask, 走到 FINAL CHANCE → break. **倒计时无法翻越决断 ceiling**.
- DeepSeek V3 没装件 5 c/d 也直接 emit edit_file. **强模型自带决断**.

**含义**: 件 5 (c+d) 对 M3 价值有限 (没翻 ceiling), 对强模型冗余 (强模型不需要). **本质是模型决断力 ≤ 阈值时, scaffold 兜不住**.

### Ceiling B: 知识 (普世)

- 两个模型都猜错 `slashCommands` 在 dev-repl.mjs (实际不存在, 真实结构是 `applySlash` 在 `slash-commands.mjs`).
- DeepSeek edit_file 的 search 串 (`const slashCommands = {...}`) 不存在 → edit fail → 11 次 grep 都返回 0.
- 这是 **task prompt 设计问题**: 没告诉模型 "如果找不到, 真实文件可能是别的". 任何模型都猜错.

**含义**: 提升 task prompt 质量 (or 给模型工具发现真实位置) 才能翻这道坎, 跟件 5 无关.
